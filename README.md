## 01 · 关于我

> 一个好用的工具，应该让人忘记它的技术复杂度。

我是**九熙雨（JXY）**，一名全栈方向的独立开发者。习惯一个人走完整条链路：需求拆解、数据建模、接口实现、界面交互，一直到部署上线和后续维护。后端是我的基本盘，前端与 AI 应用是我持续往外扩的边界。

- **后端基本盘** —— Java / Spring Boot / MyBatis 起家，写过完整的业务系统；后来用 Python / FastAPI + SQLAlchemy 做过前后端分离的全栈项目。在意的不是「接口能通」，而是分层是否清楚、SQL 是否会拖后腿。
- **前端自己动手** —— Vue 3 + Vite + Element Plus + Pinia 组整套界面，也保留原生 HTML / CSS / JavaScript 的手写能力；路由守卫、状态管理与交互动效都自己扛。
- **AI 应用落地** —— LangChain 调用链、RAG 检索增强、向量库（Qdrant），以及文本分类方向的 BERT / FastText 微调与大模型 API 对比。判断标准只有一个：它有没有真的解决那个问题。
- **跨端与自动化** —— Node.js 本地服务、Python 桌面自动化与 OpenCV 视觉识别，把「反复手动操作」变成「一次点击」。
